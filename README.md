# Mihriban'ın Mutfağı

Geleneksel Türk ev yemekleri — 167 tarif. Vite + React + TypeScript + Tailwind.

## Geliştirme

```bash
npm install
npm run dev
```

## Derleme

```bash
npm install
npm run build
npm run preview
```

Tarifler `src/recipeData/` içinde gömülü (APK'dan kurtarılan JSON). Tabak görselleri `public/plates/` altındadır.

## Stack

- Vite 8 + React 19 + TypeScript
- Tailwind CSS 4
- React Router 7
